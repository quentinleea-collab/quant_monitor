# Quant v3

量化监控系统 v3 版本。包含回测搜索、条件组合、随机森林 ML 和蒙特卡洛模拟功能。

## 核心文件

| 文件 | 职责 |
|------|------|
| `quant_v3.py` | 主脚本 |
| `_config_v3.py` | 配置 |
| `_backtest_v3.py` | 回测引擎 |
| `_loader_v3.py` | 数据加载 |
| `_search_v3.py` | 条件搜索 |
| `_indicator_v3.py` | 技术指标 |
| `_rf_ml_v3.py` | 随机森林 ML 模块 |
| `_monte_carlo_v3.py` | 蒙特卡洛模拟 |
